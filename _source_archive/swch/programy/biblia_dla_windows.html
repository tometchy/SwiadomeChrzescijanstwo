Wymagania:

Program Biblia został zaprojektowany do pracy w systemach 32-bitowych, takich jak Windows 95, Windows 98, Windows NT. Program powinien działać na tych platformach bez większych problemów. Testowałem program na Win95, Win NT oraz niedawno na Win98. Program wymaga niespełna 20 MB wolnego miejsca na twardym dysku. (ok. 15MB). Jeżeli chodzi o ilość RAM, to jeśli sam Windows 95 jest w stanie się uruchomić, to program będzie działał, przy czym jak zwykle, im więcej RAM'u tym lepiej. Najlepiej mieć min. 8MB (kto teraz odpala Win95 na miejszej ilości?.

Ktoś z was pytał czy program uruchomi się w systemach: Win 3.11, OS/2, MacOs, Linux. Niestety nie! :(

Opis:

Program służy do wyświetlania tekstu biblijnego. "Obsługiwane" są trzy tłumaczenia Biblii:
  • Biblia Gdańska,
  • Biblia Warszawska (popularnie zwana nowym przekładem - brytyjskim),
  • Biblia Tysiąclecia,
Program jest aplikacją MDI (Multi Document Interface), czyli można otwierać, używać wiele okien w tym samym czasie.

Do poruszania się po Biblii służy pasek nawigacyjny, gdzie można wybierać poszczególne księgi, rozdział i wersety. W jendym oknie wyświetlany jest jeden rozdział. Zaznaczone wersety w danym oknie można skopiować do schowka, zapisać do pliku tekstowego lub wydrukować. Wybrany werset można porównać z tym samym wersetem, ale w innym tłumaczeniu.

Program ma możliwość prostego wyszukiwania wersetów, zawierające zadane wyrazy ("po słowach").
Każde okno wywietlające tekst biblijny, posiada tzw. "listę znalezionych wersetów", czyli listę rezultatem szukania. Do poruszania się po tej liście służy pasek "Lista wersetów". Listę wersetów (jeśli nie jest pusta ) można zapisać do pliku tekstowego.

Możliwa jest zmiana czcionki wywietlania tekstu, oraz poszczeglnych kolorów.

Instalacja:

Po pobraniu wszystkich plików należy uruchomić biblia_win_14.exe (lub biblia_dla_windows_14.exe), aby uruchomić instalator. Przy instalacji najlepiej jest wybrać wyszystkie dostępne opcje instalacji.

Program instalacyjny zapyta o katalog docelowy instalacji, czy sporządzić kopię zapasową plików, nazwę grupy w Menu Start, itd. Nie powinno być żadnych problemów.

Skopiowane pliki są wielkości umożliwiającej umieszczenie ich na poszczególnych dyskietkach. Instalację można przeprowadzić zarówno z dysku twardego, jak i bezpośrednio z dyskietek!
