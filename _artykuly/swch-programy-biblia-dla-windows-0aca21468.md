<h2>Wymagania:</h2>
<blockquote>Program Biblia został zaprojektowany do pracy w systemach 32-bitowych, takich jak Windows 95, Windows 98, Windows NT. Program powinien działać na tych platformach bez większych problemów. Testowałem program na Win95, Win NT oraz niedawno na Win98. Program wymaga niespełna 20 MB wolnego miejsca na twardym dysku. (ok. 15MB). Jeżeli chodzi o ilość RAM, to jeśli sam Windows 95 jest w stanie się uruchomić, to program będzie działał, przy czym jak zwykle, im więcej RAM'u tym lepiej. Najlepiej mieć min. 8MB (kto teraz odpala Win95 na miejszej ilości?.<br/>
<br/>
Ktoś z was pytał czy program uruchomi się w systemach: Win 3.11, OS/2, MacOs, Linux. Niestety nie! :(</blockquote>
<h2>Opis:</h2>
<blockquote>Program służy do wyświetlania tekstu biblijnego. "Obsługiwane" są trzy tłumaczenia Biblii:
<ul>
<li>
<b>Biblia Gdańska,</b></li>
<li><b>Biblia Warszawska</b> (popularnie zwana nowym przekładem - brytyjskim)<b>,</b></li>
<li><b>Biblia Tysiąclecia,</b></li>
</ul>
</blockquote>
<center><img alt="Biblia dla Windows - widok programu" border="0" height="501" src="../../assets/legacy/swch/programy/images/biblia_w.gif" width="645"/></center>
<blockquote>Program jest aplikacją MDI (Multi Document Interface), czyli można otwierać, używać wiele okien w tym samym czasie.
<p>Do poruszania się po Biblii służy pasek nawigacyjny, gdzie można wybierać poszczególne księgi, rozdział i wersety. W jendym oknie wyświetlany jest jeden rozdział. Zaznaczone wersety w danym oknie można skopiować do schowka, zapisać do pliku tekstowego lub wydrukować. Wybrany werset można porównać z tym samym wersetem, ale w innym tłumaczeniu.
<p>Program ma możliwość prostego wyszukiwania wersetów, zawierające zadane wyrazy ("po słowach").
<br/>Każde okno wywietlające tekst biblijny, posiada tzw. "listę znalezionych wersetów", czyli listę rezultatem szukania. Do poruszania się po tej liście służy pasek "Lista wersetów". Listę wersetów (jeśli nie jest pusta ) można zapisać do pliku tekstowego.
<p>Możliwa jest zmiana czcionki wywietlania tekstu, oraz poszczeglnych kolorów.
<p>Więcej informacji znajduje się w systemie pomocy programu.</p></p></p></p></blockquote>

Jeśli komputer nie będzie umiał dopasować wpisanej przez ciebie referencji do istniejących nazw ksiąg (aliasów), to rozwinie się okno z nazwami ksiąg, a ty musisz już takową sobie wybrać. :) 
<li>Zrobiłem wyświetlanie wyjustowanego tekstu. Moim zdaniem powinno to poprawić komfort czytania i korzystania z Biblii.

</li></li></li></li></li></li></li></li></ul>

<h2>Instalacja:</h2>
<blockquote>Po pobraniu wszystkich plików należy uruchomić <b>biblia_win_14.exe</b> (lub biblia_dla_windows_14.exe), aby uruchomić instalator. Przy instalacji
najlepiej jest wybrać wyszystkie dostępne opcje instalacji.
<p>Program instalacyjny zapyta o katalog docelowy instalacji, czy sporządzić kopię zapasową plików, nazwę
grupy w Menu Start, itd. Nie powinno być żadnych problemów.
<p>Skopiowane pliki są wielkości umożliwiającej umieszczenie ich na poszczególnych dyskietkach. Instalację można przeprowadzić zarówno z dysku twardego, jak i bezpośrednio z dyskietek!</p></p></blockquote>
